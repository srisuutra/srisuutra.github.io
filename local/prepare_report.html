Prepare a backtest report for the website

Takes the report file from the backtest tool and makes the public copy: strategy and logic names are replaced by neutral labels (ND, D1, D2...), so they are not readable in your public GitHub repository. Numbers are not changed. Keeps only the two published strategies (Non-directional; Directional = all other groups combined, parallel book only). Everything runs in this page; nothing leaves it unless you press Publish to GitHub.

GitHub connection (set up once)

Lets this page publish straight to your website repository, so you do not have to upload files by hand. Create a token once: GitHub → your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: Only select repositories → srisuutra.github.io. Permissions: Contents = Read and write. Paste the token below. It is kept only in this browser (never exported or sent anywhere except github.com).
