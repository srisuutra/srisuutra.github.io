Prepare a backtest report for the website

Takes the report file from the backtest tool and makes the public copy: strategy and logic names are replaced by neutral labels (ND, D1, D2...), so they are not readable in your public GitHub repository. Numbers are not changed. Everything runs in this page; nothing is uploaded.

Step 1. Choose the report file from the backtest tool (the big .json file).

Step 2 (optional). Choose the current reports/index.json from your repo, so older reports stay listed. Skip this to start a fresh list.
