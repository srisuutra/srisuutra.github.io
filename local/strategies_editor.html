SRISUUTRA - Strategies editor

Edit the share codes shown on the website's Strategies tab. Type the strategy link and share code for each strategy, then press Publish to GitHub. Nothing is sent anywhere until you do.

  1. Type or paste each strategy's link and share code. Add or remove strategies as needed.
  2. Click Publish to GitHub (after the one-time connection below). The site updates in about a minute.
  3. No token? Click Download share-codes.json instead and upload it by hand:
  4. On GitHub open the repository srisuutra.github.io, click Add file → Upload files, drop the file in the top level (it replaces the old one) and click Commit changes. The site updates in about a minute.
GitHub connection (set up once)

Create a token once: GitHub → your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
