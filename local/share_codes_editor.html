SRISUUTRA - Share codes editor

Edit the share codes shown on the website's Share Codes tab. Works offline in your browser; nothing is sent anywhere.

  1. Type or paste each strategy's share code. Add or remove strategies as needed.
  2. Click Download share-codes.json.
  3. On GitHub open the repository srisuutra.github.io, click Add file → Upload files, drop the file in the top level (it replaces the old one) and click Commit changes. The site updates in about a minute.
